# Packaging icons

These are lossless format wrappers of the existing desktop icon,
`VibeRe.Desktop/Assets/avalonia-logo.ico`, preserving the project's current
placeholder identity. `app.png` is its embedded 256×256 PNG. `app.icns` contains
that same PNG as the standard `ic08` (256×256) element; no generated artwork or
image resampling is used. Windows uses the source ICO directly.

Replace all three together when VibeRe receives its own approved app icon.
